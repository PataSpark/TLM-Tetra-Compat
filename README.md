# TLM-Tetra-Compat

A Minecraft Forge compatibility mod that allows maids from **Touhou Little Maid** to use modular bows and crossbows from **Tetra**.

## Features

### Modular Bows
- Allows Touhou Little Maid maids to use Tetra modular bows.
- Supports Tetra's modular weapon modifications and attributes.

### Modular Crossbows
- Allows maids to load, aim, and fire Tetra modular crossbows.
- Supports crossbow loading mechanics, Multishot, Piercing, and Honing.
- Supports compatible modular components and attachments, including components added by other mods.
- Correctly handles the loaded crossbow holding animation for GeckoLib-based maid models.

## Requirements

| Component | Version |
|---|---|
| Minecraft | 1.20.1 |
| Mod Loader | Minecraft Forge 47.x |
| Touhou Little Maid | 1.5.3 or later |
| Tetra | 6.14.2 or later |
| Tetra dependencies | Install the dependencies required by Tetra |

**Note:** Development and testing were performed using Touhou Little Maid 1.5.3, Tetra 6.14.2, and Forge 47.4.20. Compatibility with newer versions is not guaranteed.

## Installation

1. Install Minecraft Forge for Minecraft 1.20.1.
2. Install Touhou Little Maid and Tetra, including their required dependencies.
3. Download TLM-Tetra-Compat.
4. Place the mod's `.jar` file in your Minecraft `mods` folder.
5. Launch Minecraft.

This mod requires both Touhou Little Maid and Tetra to function.

## Compatibility

TLM-Tetra-Compat integrates Tetra modular ranged weapons into Touhou Little Maid's combat behavior.

It is designed to work with Tetra's modular weapon system, including compatible modular parts provided by other mods.

Compatibility with every third-party addon or modpack is not guaranteed.
